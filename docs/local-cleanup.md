# 本机云端绑定与手动清理

## 在软件中切换云端库

1. 在“中转模式服务”中停止中转服务，再打开当前云端凭证库。
2. 点击“创建加密备份”，选择新的文件名并设置备份密码。
3. 保存成功后，选择“解除本机绑定”。默认选项是“保留绑定”；取消或关闭对话框也会保留。
4. 软件重新读取并解密备份，确认它与本次导出的快照一致，然后关闭当前库和 helper，删除该库在本机记住的恢复码、云授权及协调服务器连接配置。
5. 界面显示“尚未绑定云端库”后，可以“初始化本机库”或“从备份恢复”；也可以通过“配置云存储”配置目标库，再选择“连接已有库”或“建立云端库”。重启后仍可选择。启动中转服务需要另行操作。

云端库、云盘文件和 etcd 中的状态不会被删除或修改。其他电脑仍可使用原库。
确认期间其他客户端的更新不会使解除绑定失败；导出的备份只代表导出时的快照。
备份损坏、密码错误或校验不一致会阻止解除绑定。

软件保留本机授权密钥、设备配对、其他库的云配置、版本回滚保护记录和不含凭证的锁标记。
如果原库由本机库迁移而来，遗留的旧本机文件继续保持停用，不会自动打开。
显式初始化或恢复本机库时，旧文件及停用标记会先保留到 `retired-local-<凭证库编号>/`，再建立本机库。
重新连接同一云端库时，需要重新配置云授权，并提供该库的恢复码。
恢复码和备份密码是两个不同用途的秘密，请分别保管。

若清理被文件占用或权限问题阻止，软件不会报告完成或回退到本机库。
解除占用或修复权限后，刷新存储状态或重新打开软件，会继续完成已经确认的解除操作。
不要手工删除或改写 `backend-v1` 文件来强行切换；它记录中断恢复所需的状态。

切换目标库不会把原库的账号搬过去。这里支持的是选择另一份已经配置好的云端库，
或建立空的新库；不提供把同一份库从 OneDrive 原地迁移至 Google Drive 的功能。
不要将备份恢复成第二份库后让两份副本同时继续认证，否则计数器会各自变化。

## 归还或转卖电脑：由用户执行的清理

解除云端绑定不是整机清理。以下操作不提供软件按钮，按实际需要手动执行。

1. **先确认可恢复。** 把需要保留的加密备份保存到另一台设备或外置存储，单独保存密码与云端恢复码。确认新电脑能打开需要继续使用的云端库。新电脑的本机授权密钥和设备配对需重新建立；它们不包含在凭证库备份内。
2. **停止并退出。** 停止中转服务，退出所有 Controller、CLI 和 `PicoFidoStorage` helper，避免内存中的密钥、自动启动和后台写入继续存在。
3. **清除本机应用数据。** 使用文件管理器删除下列当前系统对应的数据目录。该操作会一起删除本机库、迁移后停用的旧库、本机授权密钥及其历史备份、所有云配置、设备配对记录、网络设置草稿、设备名称、版本记录及锁标记。先将要保留的备份移出此目录。

   | 系统 | 数据目录 |
   | --- | --- |
   | macOS | `~/Library/Application Support/PicoFido2Remote` |
   | Windows | `%LOCALAPPDATA%\PicoFido2Remote` |
   | Linux | `$XDG_DATA_HOME/PicoFido2Remote`；未设置该变量时为 `~/.local/share/PicoFido2Remote` |

4. **清除应用专用的系统钥匙串条目。** macOS 使用“钥匙串访问”，Linux 使用当前桌面的 Secret Service 密码管理工具。只删除下表对应条目，且应先完成所有本机应用数据的备份或删除：这些密钥可能保护多份库的配置，删除后仍留下的加密文件将无法打开。Windows 使用系统 DPAPI，不要为此删除系统 DPAPI 密钥或其他应用的凭证。

   | 用途 | 服务 / schema | 账号 |
   | --- | --- | --- |
   | macOS 本机数据加密 | `PicoFido2Remote` | `data-protection-key-v1` |
   | Linux 本机数据加密 | `org.picofido2.remote.DataProtection` | `data-protection-key-v1` |
   | 云配置加密 | `PicoFido2Remote-storage` | `profile-key-v1` |

5. **检查目录之外的副本与偏好。** 按需清理自己保存的备份、恢复码、客户端证书及私钥文件、诊断资料、下载目录副本，以及系统备份中的相关副本。删除应用目录不会清除这些文件。软件的窗口和自动启动偏好也单独保存；退出软件后，可清理当前系统对应的位置：

   | 系统 | 用户偏好位置 |
   | --- | --- |
   | macOS | `~/Library/Preferences/com.picofido2remote.Pico FIDO Controller.plist`；如存在，也检查 `org.picofido2.controller.plist` |
   | Windows | 注册表 `HKEY_CURRENT_USER\Software\PicoFido2Remote\Pico FIDO Controller` |
   | Linux | `$XDG_CONFIG_HOME/PicoFido2Remote/Pico FIDO Controller.conf`；未设置该变量时位于 `~/.config/` 下 |

6. **处理旧电脑的授权。** 如需让旧电脑持有的复制凭证失效，请通过自己的协调服务器管理流程撤销该电脑独立的客户端证书或用户权限；不要删除多人共用的 etcd 服务、角色或凭证库状态。需要撤销云盘 OAuth 授权时，在云服务的应用授权管理中执行，并先确认是否会影响其他电脑。设备中旧电脑的授权公钥，可通过 Controller 的现有“移除所选授权”流程移除。

如果整台电脑即将交给他人，应最后使用操作系统提供的抹除或恢复出厂设置流程。
仅删除应用文件不等同于清除系统用户、浏览器登录、系统备份和整机上的其他个人数据。
