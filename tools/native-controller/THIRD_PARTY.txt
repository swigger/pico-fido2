Mbed TLS is used under its Apache-2.0 license option. The complete upstream
license is copied into LICENSES/ as MBEDTLS-LICENSE.txt. Its bundled
Project Everest code (copyright INRIA and Microsoft Corporation, 2016-2018) is
Apache-2.0; its bundled p256-m code (Manuel Pegourie-Gonnard) is used under the

Source and original notices are retained in the verified CMake dependency tree.

Windows networking, CNG and DPAPI are operating-system APIs. There is no Python,
OpenSSL DLL or separate TLS runtime dependency in the delivered executable.
The GUI uses dynamically linked Qt; release packages include Qt and its notices
under LICENSES/Qt. The CLI does not depend on Qt.
